# PLC、触摸屏与 MQTT 离线联调台

手上只有程序时，在一台 Windows 电脑上先测物理按钮、PLC 状态、触摸屏读数和 MQTT 请求与回执。可使用内置模型，也可接上正在本机运行的厂家仿真程序、触摸屏工程或网关程序。

## 快速开始

1. 在 [Releases](https://github.com/Clout333/plc-mqtt-simulator/releases/latest) 下载 `plc-mqtt-simulator-v版本号-windows-x64.zip`，完整解压到可写目录。
2. 双击 **00_一键启动.cmd**，等窗口显示“操作页面已打开”后按任意键即可关闭提示。若浏览器没有显示，可手动打开窗口中的网址。第一次使用会进入工程接入助手。没有工程时点 **测试本机示例**，查看 PLC 读数和设备回执。有工程时拖入文件或粘贴路径，点 **查看连接步骤**。
3. 进入联调台测试启动、停止、复位和急停。物联网按钮可自定义主题、报文和回执字段。默认网页在 [127.0.0.1:19860](http://127.0.0.1:19860/)。
4. 遇到问题时打开“运行诊断 → 导出诊断报告”。网页打不开时双击 **04_导出诊断.cmd**。报告仅由用户手动分享。

| 程序 | 接入方式 |
| --- | --- |
| 西门子 S7-200、博途，海为、三菱、汇川 PLC | 从支持对外通信的厂家运行端或本机协议桥读取，依工程选择 Modbus TCP、S7 或 MC 3E。先对照一个已知变量，再联调任务点表。 |
| 海为、昆仑通态、威纶通触摸屏 | 通过 PC 运行端对读变量，可单独验证屏，也可以连接本机 PLC 模型。 |
| MQTT 设备端 | 由触摸屏或网关负责连接，本机提供 Broker 和可自定义的物联网按钮。 |
